# 📊 Portfolio Data Analyst – Telco Customer Churn

## 1. Présentation du projet

Ce projet consiste à analyser les données clients d'une entreprise de télécommunications afin de comprendre les facteurs associés à la résiliation des abonnements (Customer Churn).

L'objectif est d'identifier les profils de clients les plus exposés au risque de départ et de proposer des pistes d'amélioration pour renforcer leur fidélisation.

## 2. Objectifs de l'analyse

- Explorer et comprendre les données clients.
- Contrôler la qualité des données et identifier les valeurs manquantes.
- Mesurer le taux global de résiliation.
- Identifier les caractéristiques associées au churn.
- Construire des modèles de Machine Learning.
- Concevoir un tableau de bord interactif avec Power BI.
- Formuler des recommandations métier.

## 3. Outils utilisés

| Outil | Utilisation |
|---|---|
| Excel | Exploration des données et tableaux croisés dynamiques |
| SQL | Nettoyage, requêtes et analyses statistiques |
| Python / Pandas | Préparation et exploration des données |
| Machine Learning | Modélisation et prédiction du churn |
| Power BI | Visualisation et création du tableau de bord |

## 4. Principaux constats

L'analyse a notamment permis d'identifier :

- Un taux de churn plus élevé chez les clients ayant un contrat mensuel.
- Une exposition importante des nouveaux clients.
- Un taux de résiliation élevé chez les utilisateurs du paiement par chèque électronique.
- Une différence importante selon le type de service Internet.

Ces résultats permettent de mieux cibler les segments nécessitant une attention particulière.

## 5. Recommandations métier

- Encourager les nouveaux clients à souscrire des contrats de plus longue durée.
- Mettre en place des offres de fidélisation durant les premiers mois.
- Améliorer le suivi de la qualité du service Fibre optique.
- Étudier les difficultés liées aux modes de paiement.
- Renforcer l'accompagnement des clients les plus exposés.
