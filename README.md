# 📊 Portfolio Data Analyst – Analyse du Customer Churn

Bienvenue sur mon portfolio Data Analyst.

Ce dépôt présente un projet complet d'analyse de données réalisé dans le cadre de ma formation Data Analyst & IA chez Datasuits en 2026.

## 1. Présentation du projet

Ce projet consiste à analyser les données clients d'une entreprise de télécommunications afin de comprendre les facteurs associés à la résiliation des abonnements (Customer Churn).

L'objectif est d'identifier les profils de clients les plus exposés au risque de départ et de proposer des solutions permettant d'améliorer leur fidélisation.

## 2. Objectifs de l'analyse

- Explorer et comprendre les données clients.
- Contrôler la qualité des données.
- Identifier et traiter les valeurs manquantes.
- Mesurer le taux global de résiliation.
- Identifier les facteurs associés au churn.
- Développer des modèles de Machine Learning.
- Concevoir un tableau de bord interactif.
- Formuler des recommandations métier.

## 3. Outils et compétences techniques

| Outil | Utilisation |
|---|---|
| Excel | Exploration des données et tableaux croisés dynamiques |
| SQL | Nettoyage, requêtes et analyses statistiques |
| Python / Pandas | Préparation et analyse exploratoire |
| Machine Learning | Classification et prédiction du churn |
| Power BI | Modélisation, DAX et visualisation interactive |

## 4. Principaux résultats

L'analyse des 7 043 clients a permis d'identifier plusieurs facteurs associés à la résiliation.

| Indicateur | Résultat |
|---|---:|
| Nombre total de clients | 7 043 |
| Clients ayant résilié | 1 869 |
| Taux global de churn | 26,54 % |
| Churn des contrats mensuels | 42,71 % |
| Churn des clients avec 0 à 12 mois d'ancienneté | 47,44 % |
| Churn du paiement Electronic Check | 45,29 % |
| Churn du service Fiber Optic | 41,89 % |

Ces résultats mettent notamment en évidence une exposition plus importante des nouveaux clients et des clients disposant de contrats mensuels.

## 5. Recommandations métier

À partir des résultats obtenus, plusieurs actions peuvent être proposées :

- Encourager les nouveaux clients à choisir des contrats de plus longue durée.
- Mettre en place des offres de fidélisation durant les premiers mois.
- Améliorer le suivi de la qualité du service Fibre optique.
- Étudier les difficultés liées aux modes de paiement.
- Renforcer l'accompagnement des clients les plus exposés.

Les facteurs identifiés représentent des associations statistiques et ne démontrent pas nécessairement une relation de causalité.
